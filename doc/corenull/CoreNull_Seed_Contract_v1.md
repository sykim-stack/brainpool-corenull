# CoreNull Seed Contract v1

확정: 2026-11-06  
갱신: 2026-11-10 — 초대장 = 씨드 생애 기록 (run 격리 해제)

## 한 줄

글을 쓰거나 기존 글을 선택해 시작하고, 종료 시 열매로 닫혀 마당·거실·서재로 이동·보관한다.

## 원칙

- **씨드는 하나**다. run은 실행 단위일 뿐 씨드 정체성이 아니다.
- 씨드를 끄거나 다시 시작해도 **성장 역사는 단절되지 않는다**.
- 초대장(`/s`)은 run 묶음이 아니라 **시작글부터 지금까지의 생애 기록**을 보여 준다.

## 범위

- **시작 게시글** (`start_post_id`) 필수
- **종료일** (`end_date`) 필수
- 초대장에 들어가는 글 = 같은 방 + `created_at >= start_at` (삭제 제외)
- 이전 run의 released 글도 초대장에 **유지** (재시작해도 탈락하지 않음)
- 시작글 **이전** 글은 방에 남되 초대장 밖

## 시작 경로

1. **write**: 이 글로 씨드 시작 (새 글 = start) + 종료일
2. **방 설정**: 기존 글 하나 선택 + 종료일 → 씨드 시작

시작 시 서버가 한 번에:
- `run_id` 발급
- `corenull_seed_pages` 생성 (`status=open`, `start_post_id`, `start_at`, `end_date`)
- 방 `seed_mode=true`, `bloom_date=end_date`
- 범위 글에 `meta.seed` 태깅 (시작글 `role=start`, 나머지 `role=member`)
- 이후 새 글(종료 전) 자동 동일 run 태깅

## 진행

- 초대장 `/s/[slug]` = 메모 + **시작글~현재 성장 기록** (run 무관, 시간순)
- 방 설정 = 링크 · 메모 · **해제만** (시작 UI와 분리하되, 미시작 시 기존글 선택 시작은 방 설정에 둠)

## 종료 → 열매

- end_date 경과 시(또는 확정 API) `status=fruit`
- 구간 글 `phase=fruit`
- 방 `seed_mode=false` (방은 유지)
- 열매는 **마당 / 거실 / 서재**에서 보이·보관 가능
- 초대장에는 열매 포함 생애 기록 유지

## 해제

- `status=released` · 열매 없음 · phase=released
- 해제 후에도 초대장 생애 기록은 유지 (글 삭제·탈락 없음)

## UI 위치

| 동작 | 위치 |
|------|------|
| 새 글로 시작 | write |
| 기존 글로 시작 | 방 설정 |
| 초대장·메모·해제 | 방 설정 (진행 중) |
| 열매 열람 | 마당·거실·서재·`/s` |

## 비범위

- CoreHub outbox 세부 (fact push는 기존 유지)
